# Release 0.1.0

**CompilerSutraPerf** 0.1.0 · **Status:** First public MVP (superseded by [0.3.0](/docs/project/compilersutra-perf/releases/0.3.0/))

Package: [PyPI: `compilersutra-perf`](https://pypi.org/project/compilersutra-perf/).

## Install this release

```python
pip install 'compilersutra-perf==0.1.0'
```

## What shipped

- CLI: `run`, `profile`, `visualize`, `dashboard`, `list-backends`, `list-experiments`, `list-devices`  
- CPU C/C++ compile-and-run, LLVM IR emission, Linux `perf` counters  
- Warmup / repeat runs, CPU affinity, native C++ runner  
- OpenCL execution + argument binding  
- Vulkan shader compile + validation  
- HIP compile-and-run + rocprof-style profiling  
- GPU device discovery; JSON/CSV; HTML + Streamlit dashboard  

## Known gaps (at 0.1.0)

- No workload matching / baseline regression store  
- No Vulkan compute dispatch  
- No CUDA / Metal
