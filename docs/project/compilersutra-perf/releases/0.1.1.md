# Release 0.1.1

**CompilerSutraPerf** 0.1.1 · **Status:** Infrastructure (superseded by [0.3.0](/docs/project/compilersutra-perf/releases/0.3.0/))

Package: [PyPI: `compilersutra-perf`](https://pypi.org/project/compilersutra-perf/).

## Install this release

```python
pip install 'compilersutra-perf==0.1.1'
```

## Highlights

- Experimental macOS CPU docs and CI coverage  
- Native CPU runner more portable (Linux-only affinity isolated)  
- Optional OpenCL discovery when dependency missing  
- macOS-incompatible Vulkan `libdl` linkage removed  
- Improved macOS `powermetrics` diagnostics  
- macOS CPU smoke in CI
