# Release 0.3.0

**CompilerSutraPerf** 0.3.0 · **Date:** 2026-11-08 · **Status:** Current · Alpha (not v1.0)

Extensibility release: out-of-tree plugins, versioned result schema v2, CompilerSutraRun (`csrun`) Vulkan execute, and honest `emulated` vs `hardware` evidence labels. Package: [PyPI: `compilersutra-perf`](https://pypi.org/project/compilersutra-perf/).

## Install this release

```python
pip install 'compilersutra-perf==0.3.0'
# or latest 0.3.x:
# pip install 'compilersutra-perf>=0.3.0,<0.4'
csperf --version
csperf quickstart --output-dir results/quickstart
```

Extras: `pip install 'compilersutra-perf[excel,pdf,visualize]'` — see [PyPI](https://pypi.org/project/compilersutra-perf/).

Requires **Python 3.11+**. Linux is primary. Windows → WSL2.

If `pip` cannot find 0.3.0 yet, the tag is still publishing — use the [GitHub release](https://github.com/compilersutra/CompilerSutraPerfTool/releases) or install from the `feature/0.3-extensibility` tree until the wheel is live.

## Changelog (summary)

### Added

- Plugin contracts and entry-point discovery (`csperf.plugins`)
- Example out-of-tree plugin (experiment + backend + visualizer)
- `BackendRunner` / `DeviceLister` registry dispatch
- Result schema v2 with `measurement_type`, `workload_id`, `comparison_key`
- Provenance hashes and toolchain fingerprint
- `csperf list-toolchains`; `--compiler-config` presets
- GPU profiler plugin adapter (HIP rocprof*)
- `csperf visualize --renderer` visualizer plugins
- Experiment plugin defaults (`compiler_flags` / `tile_size`) applied at compile time
- CompilerSutraRun (`csrun`) adapter for Vulkan execute and counter mapping
- QEMU / cross-ISA user-mode runs labeled `emulated` (never `hardware`)

### Changed

- Vulkan prefers csrun when available; without csrun, shader validation remains `partial`
- Schema validators reject malformed provenance / incomplete v2 payloads

### Deferred

- Observatory runners that consume `ToolchainProvider` (IR/asm/static) → [0.4.0](https://github.com/compilersutra/CompilerSutraPerfTool/milestone/6) ([#163](https://github.com/compilersutra/CompilerSutraPerfTool/issues/163))
- Baseline store / autotune / NUMA remain later
