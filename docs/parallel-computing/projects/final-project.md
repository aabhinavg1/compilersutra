# Final project

## What you'll learn

- One problem, two implementations, matching results.
- A short measuring note from your runs.

## Video

The recording for this page is not up yet. These notes are the script for that recording and for the short slide deck.

## Concept

Pick a problem you can check: the sum, a map, a small matrix-vector product, or a histogram. Implement it serial, and implement it again with one parallel tool from this course. The results match. The note says what was still serial, what the tool was, and what you measured. A mixed quiz across the chapters you used is the review.

## Picture

```text
serial result, parallel result, one paragraph.
```

## Hands-on

The reader of your note should be able to tell which chapter's tool you used without guessing.

## What changed the time

Include the times you measured and the command you built with.
