# The list of numbers we keep reusing

## What you'll learn

- One list of integers is the example for the whole course.
- Later chapters split that same list in a new way.

## Video

The recording for this page is not up yet. These notes are the script for that recording and for the short slide deck.

## Concept

The list is 2, 7, 1, 8, 2, 8. The job is to add it up. The serial result is 28. Every later lesson starts from this list, so a new chapter does not mean a new problem.

## Picture

```text
2 + 7 + 1 + 8 + 2 + 8 = 28
```

## Hands-on

Add the list on paper, left to right. Keep 28. That is the answer the parallel versions have to match.

## What changed the time

One person, one pass. The computer version of this timer shows up in Chapter 1.
