# Weekly Problem Briefs

Every week we pick **one problem** companies and open projects are working on in compilers and AI runtimes (LLVM, MLIR, ONNX, GPUs, CPUs, NPUs).

We write it so you can follow even if you are new to the stack. We still name the real APIs and links, so you can go deeper when you are ready.

This is not general tech news. No funding stories. No hype rankings. Just: what is hard, who is working on it, and what you can try.

## What you will find in each brief

1. **The problem** — in plain language, then the precise name  
2. **Who is trying to solve it** — projects and what they own  
3. **What you should try** — a small check you can run or inspect  
4. **What to watch next** — a few public links  
5. **Read on CompilerSutra** — lessons that teach the background
