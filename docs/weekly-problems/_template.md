# YYYY-WNN: Question or claim an engineer would argue about

Two sentences max. State the mechanism and the cost if you ignore it.

## The problem

One constraint. Where it sits (file, session, pass, device boundary). What breaks or gets expensive.

## Worked example (required)

A tiny concrete case a beginner can follow:

- A small graph, IR snippet, or code listing
- A “good” path and a “bad” path (or before / after)
- What the reader should look at (print, count, or time)

Do not leave the brief as only abstract paragraphs.

## Who is trying to solve it

Named projects and the exact surface they own (API, dialect, EP, backend). No company parade without a stack hook.

## What you should try

The check: what to print, count, or time. Cold vs warm if compile is involved.
