# Labs

Guided practical work — not passive browsing. Pick one lab direction and finish it.

## Core lab directions

### Build a Toy Compiler

Connect frontend structure, IR generation, and executable output in one scoped project.

### Write Your First LLVM Pass

Move from reading about passes to implementing a real analysis or transformation.

### SSA and CFG Lab

Take a small control-flow example and inspect blocks, edges, phi nodes, and dominance.

### Benchmark and Optimization Lab

Compare compiler choices, flags, or workloads and document what changes in practice.
