# Overview

This section is a quick starting point for beginner computer terminology.

It exists to answer two questions:

- What is this section about?
- How does it connect to how computer works?

## What this section covers

You will see the core words that keep showing up across programming, compilers, operating systems, and low-level systems work.

The main idea is simple:

- a **computer program** describes what you want the machine to do
- **source code** is how you write that program
- the rest of the toolchain turns that source into something the CPU can run

## Why the overview exists

If you are new, jumping straight into compiler or CPU articles can feel too abrupt.
This overview gives you the landing page first, then the deeper articles after it.
